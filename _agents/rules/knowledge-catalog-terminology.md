# Knowledge Catalog Terminology Rule

* **Do NOT refer to the product as "Dataplex"** in user-facing explanations, presentations, architectures, or documentation.
* **Always use "Knowledge Catalog"** (or **BigQuery Knowledge Catalog**) instead of Dataplex.
* Note: Even when underlying `gcloud dataplex ...` CLI commands, REST endpoints (`dataplex.googleapis.com`), or `@dataplex` entry groups appear in code/scripts, refer to the product and capability as **Knowledge Catalog**.
